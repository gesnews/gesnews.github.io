About

GES-NEWS is written only for students in the Department of Geology, Environment and Sustainability (GES) and related subject areas. It brings together deadlines, internships, scholarships, field trips, volunteer opportunities, talks, courses and events in one place, not general University news.

We check every application deadline directly with the organisation that offers it. If next year’s date has not been posted yet, we say so, instead of printing an old one that might already be closed. Campus event details come from the faculty members who run them.

Nine issues a year, September to May.
Founding Editor: Dr. Antonios E. Marsellos. Co-Editor: Dr. J Bret Bennington.

Write for GES-NEWS

GES-NEWS is looking for student contributing editors. Contributors write first-person accounts of internships and field seasons, plain-language versions of their own research, reports from events and field trips. None of it is scientific writing.

To contribute a piece, or to join as a contributing editor for the year, write to the editor with GES-NEWS in the subject line.

Add an Item to the Next Issue

The co-editor and faculty contributors can open the shared working document to add or edit an item for the next issue: open the working document.

Access is limited to people the editor has added. If you are GES faculty and would like to contribute an item, write to the editor first. Items close on the Friday before each issue comes out.
